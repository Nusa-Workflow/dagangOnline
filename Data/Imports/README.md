# Folder Import Dataset (CSV / XLSX)

Folder ini disediakan sebagai direktori penyimpanan untuk mengunggah dan mengimpor file data spreadsheet:
- **Format yang didukung**: `.csv`, `.xlsx`, `.xls`
- **Kegunaan**:
  - Dataset indikator makroekonomi (Inflasi, Kurs, Suku Bunga)
  - Data harga komoditas historis (CPO, Minyak Mentah, Beras, Batubara)
  - Data transaksi katalog produk UMKM dan logistik
  - Data pelatihan / fine-tuning permodelan AI dan Knowledge Graph

File yang diletakkan di folder ini dapat dibaca oleh data pipeline dan layanan ingest ekonometrika.
